# AI Видео — установка на сервер

Видеоредактор в браузере: нелинейный монтаж, переходы, титры и субтитры, цвет, звук и вывод в MP4 — для
коротких роликов в соцсети, обучающих видео, презентаций и блогов. Со встроенным помощником на вашей
локальной модели и проектами на вашем сервере. На сервере нужны только **nginx + PHP + Ollama** (или другой
сервер модели) — то, что у вас уже есть. Ничего компилировать не нужно. Редактор полностью автономный: всё
загружается из его папки, интернет и сторонние сайты не нужны. Видео обрабатывается в браузере пользователя.

Premiere Pro — товарный знак Adobe. AI Видео не связан с Adobe и работает с распространёнными форматами
видео, звука и обмена монтажом (MP4, MOV, MKV, WebM, WAV, MP3; EDL, XML, AAF).

## Установка (5 минут)

1. **Скачайте готовую сборку.** GitHub → репозиторий `ai-premiere` → справа **Releases** →
   верхняя «Сборка N — дата» (с пометкой Latest) → файл `ai-premiere-build-N-ГГГГ-ММ-ДД.zip`.
   Какая сборка стоит у вас, видно в шапке панели помощника: «Модель: … · сборка N».
2. **Распакуйте** — внутри одна папка `ai-premiere`.
3. **Положите её на сервер** рядом с остальными приложениями: `/app/src/ai-premiere/`.
   Папку можно назвать как угодно — все пути внутри относительные. Помощник и хранилище сами найдут
   ваш `auth.php` на два уровня выше и через него — `config.php`, `.env`, адрес Ollama и модель.
4. **Папка для проектов создаётся сама**: `storage/ai-premiere` рядом с корнем сайта.
   Проверка: `https://ваш-домен/ai-premiere/api/files.php` → `{"ok":true,…}`.
5. **nginx и PHP — большие файлы.** Видео бывают большими: в «Мои проекты» загружаются файлы до
   `AI_PREMIERE_MAX_MB` (по умолчанию **1024 МБ**). Готовые блоки — в `nginx.conf.example`:
   - для `api/files.php`: **`client_max_body_size 1100m;`** (не меньше `AI_PREMIERE_MAX_MB`),
     `client_body_timeout 600s;` и `fastcgi_read_timeout 600s;`;
   - в PHP (`php.ini` или пул FPM): **`post_max_size = 1100M`**, **`upload_max_filesize = 1100M`**,
     `max_execution_time = 600`, `max_input_time = 600`; место на диске под `storage/ai-premiere`;
   - для `api/assistant.php`: `client_max_body_size 20m;` и `fastcgi_read_timeout 200s;`.
   Нужны файлы больше — поднимите `AI_PREMIERE_MAX_MB` в `.env` и эти числа вместе с ним.
6. **Откройте** `https://ваш-домен/ai-premiere/`.

Обновление — то же самое: скачать новый zip и заменить папку (свой `studio/config.js` сохраните).
Каждая сборка лежит в своей папке `b/<номер>/`, а `index.php` открывает самую новую целую, поэтому
программа заливки не может смешать файлы двух сборок. Если заливаете по FTP, лучше включить «Перезаписывать всегда».

Для проверки без входа в систему на своём компьютере:
`AI_PREMIERE_ALLOW_ANON=1 php -S 127.0.0.1:8080 -t ai-premiere` и откройте `http://127.0.0.1:8080/`.

## С чего начинается

При первом запуске интерфейс русский, тема — **Фирменная**, открыт пустой проект «Без названия».
Видео, звук, картинки и субтитры можно открыть из «Моих проектов», кнопкой «С компьютера…» в той же панели,
перетащить в окно или через Файл › Импорт. Перетащите клип из панели «Проект» на таймлайн — получится
последовательность его размера. Демо-проект редактора открывает адрес `…/?demo`.

Нужен свежий браузер с WebGPU или WebGL2 (Chrome, Edge, Firefox, Safari). Видео H.264, HEVC, VP9 и AV1
браузер декодирует сам (WebCodecs), остальное — встроенные декодеры. Звук включается после первого
нажатия на страницу: если при воспроизведении тихо, щёлкните по окну.

## Проекты и медиа

- **Ctrl+S** сохраняет проект в «Мои проекты» на сервере (значок папки в панели помощника): файл **.fcproj**
  (монтаж, титры, субтитры, эффекты) и рядом — все видео, звук и картинки, которые в нём есть и которых на
  сервере ещё нет (они загружаются один раз, ход видно внизу экрана). Первый раз спросит имя проекта.
  «Сохранить как…» — копия под новым именем.
- **Мои проекты**: список с датой и размером, поиск, открыть, переименовать, удалить (в корзину `.trash`).
  Хранятся проекты (.fcproj) и медиа: видео MP4/MOV/M4V/3GP, MKV/WebM, AVI, MXF, MPEG-TS/M2TS/MTS, MPEG;
  звук WAV/BWF, AIFF, MP3, M4A/AAC, FLAC, OGG/Opus; картинки PNG, JPEG, GIF, WebP, TIFF, BMP; субтитры SRT
  и WebVTT. Сервер проверяет содержимое по первым байтам.
- Проект открывается вместо текущего, а его медиа подтягиваются из «Моих проектов» по именам файлов.
  Видео, звук, картинку или субтитры из списка редактор добавляет в панель «Проект».
- «С компьютера…» — открыть проект или добавить медиа (браузер читает файл прямо с диска, без копии в памяти).
  Добавленные медиа уходят на сервер вместе с проектом при сохранении.
- У каждого пользователя своя папка. Проект с сервера сохраняется туда сам раз в две минуты, если в нём есть
  изменения и сейчас не идёт воспроизведение. Если сохранить не удалось, копия проекта остаётся в браузере.
  Кроме того, редактор каждые несколько секунд держит копию несохранённого монтажа и открытых медиа в
  хранилище браузера: после сбоя или закрытия вкладки они вернутся при следующем открытии.
- **Экспорт** (Файл › Экспорт › Медиа…, «Быстрый экспорт» в шапке, быстрые задачи «Скачать MP4») идёт в
  браузере и **скачивается** готовым файлом: H.264 (MP4), ProRes, DNxHR, GIF, кадры PNG/JPEG, звук WAV, MP3,
  AAC, FLAC; субтитры — SRT/VTT. Длинный ролик кодируется заметно дольше его длительности.

## Помощник

- **Совет** — объясняет, где найти функцию, разбирает монтаж, подсказывает переходы, цвет, громкость для
  соцсетей и размеры кадра. Ничего не меняет.
- **Сделай** — сам монтирует командами редактора: создаёт последовательности (в том числе вертикальные 9:16),
  ставит клипы на таймлайн, режет, удаляет со сдвигом, подрезает, меняет скорость, ставит переходы, титры и
  субтитры, правит цвет (экспозиция, контраст, температура, насыщенность), выравнивает звук и приглушает
  музыку под голосом, ставит маркеры и выводит ролик. Каждое действие отменяется (Ctrl+Z). Сколько шагов
  подряд делать и спрашивать ли перед удалением — «Настройки» внизу панели. Видео модель не смотрит: она
  видит дорожки, клипы, титры, субтитры, маркеры и (если включён «глаз») снимок экрана.
- **Быстрые задачи** (значок с квадратиками) — в одно нажатие, на выделенные клипы или на всю последовательность:
  - **Последовательность из клипа**, **Вертикальное видео 9:16**, **Квадрат 1:1**;
  - **Плавные переходы между клипами** (растворение 0,5 с на стыках видео и звука), **Плавное начало и конец**,
    **Разрезать здесь**, **Маркер здесь**;
  - **Титр в начале**, **Субтитр здесь**, **Скачать субтитры SRT**;
  - **Выровнять звук** (голос к −16 LUFS), **Приглушить музыку под голосом**, громче/тише на 3 дБ;
  - **Ярче и сочнее**, **Тёплый тон**;
  - **Скачать MP4**, **MP4 720p**, **звук MP3**, сохранить, новый проект — и готовые просьбы помощнику.
- **Быстрая строка — Ctrl+Shift+Пробел.**

### ИИ у выделения

Кнопка **ИИ** справа в шапке редактора (рядом с домиком) или **Ctrl+Alt+Пробел**. Текст в видеопроекте —
это субтитры, тексты титров, маркеры и названия клипов; с ними помощник и работает:

- выделены **субтитры** — они; выделены **титры** — их тексты; выделены другие клипы — их названия;
  ничего не выделено — **все субтитры** первой дорожки, без них — **маркеры**, а нет и маркеров — ролик целиком;
- **субтитры**: улучшить, исправить ошибки, **сократить, чтобы успевали читать** (до 15 знаков в секунду,
  до двух строк по 42 знака), расставить переносы строк; **перевод** на английский, русский, немецкий,
  испанский, китайский — заменой текста или **новой дорожкой субтитров** с тем же временем;
- **титры**: короче и ярче, исправить ошибки; **названия** клипов и маркеров;
- **публикация**: главы с таймкодами, описание ролика, варианты названия, хэштеги, что в проекте.
  Можно написать свою просьбу.

Модель видит план всего ролика (клипы со временем, титры, субтитры, маркеры), а работает с выделенным. Ответ
сначала показывается в окошке: **Заменить текст**, **Новой дорожкой субтитров**, **Копировать** или
**Ещё вариант**. Отмена — Ctrl+Z. Задания для модели — в `api/context.php`. Расшифровки речи в браузере
нет: субтитры берутся из файла SRT/VTT, набираются вручную или помощником из вашего текста.

## Оформление

Тема редактора — **Фирменная** (по умолчанию), **Светлая** или **Тёмная**: значок палитры в панели помощника,
Просмотр › Оформление или Правка › Настройки › Оформление. Выбор запоминается в браузере. Домик справа вверху
ведёт обратно на сайт (адрес — `homeUrl` в `studio/config.js`).

## Шрифты

Для титров и субтитров в сборке лежат открытые шрифты (папка `fonts/`, список — `fonts/manifest.json`):
**Liberation Sans, Serif, Mono** (по метрикам как Arial, Times New Roman и Courier New), **Carlito** (как Calibri)
и **Caladea** (как Cambria), все с кириллицей. Панель подгружает их в фоне после запуска; в списке шрифтов
титра они появляются сами. Свои шрифты (TTF/OTF) можно положить в `fonts/` и дописать в `manifest.json`.
Встроенные шрифты редактора — Inter и Noto Serif — тоже знают кириллицу.

## Настройки в `.env` (необязательно)

| Переменная | Что делает | По умолчанию |
|---|---|---|
| `AI_PREMIERE_DATA_DIR` | Где хранить проекты и медиа пользователей | `storage/ai-premiere` рядом с корнем сайта |
| `AI_PREMIERE_MAX_MB` | Самый большой файл в «Моих проектах», МБ (столько же должны пропускать nginx и PHP, см. выше) | 1024 |
| `AI_PREMIERE_MODEL` | Модель помощника (нужны tools; для «глаза» — картинки) | `GLOBAL_MODEL` |
| `AI_PREMIERE_OLLAMA_URL` | Адрес Ollama или шлюза | `OLLAMA_IP:OLLAMA_PORT` |
| `AI_PREMIERE_CONTEXT` | Размер контекста | `GLOBAL_MODEL_CONTEXT` или 32768 |
| `AI_PREMIERE_TIMEOUT` | Сколько секунд ждать модель | 180 |
| `AI_PREMIERE_MAX_TOKENS` | Длина ответа | 2048 |
| `AI_PREMIERE_AUTH_FILE` | Путь к `auth.php`, если папка лежит не в `/app/src/` | ищется автоматически |
| `AI_PREMIERE_TALERS_FILE` | `talers.php` кабинета для ИИ у выделения (цена операции и остаток) | `cabinet/talers.php` рядом с корнем сайта, если он есть |
| `AI_PREMIERE_ALLOW_ANON` | `1` — без входа (только для проверки!) | выключено |


### Откуда помощник берёт модель

Главный источник — файл **.env** вашей системы. Помощник находит его сам: рядом с папкой приложения
и выше по папкам (обычно это `.env` в корне сайта или уровнем выше). Если .env лежит в другом месте,
укажите путь в переменной `AI_ENV_FILE`. Значения из .env важнее переменных окружения процесса:
если сервер запущен со старыми переменными, а .env поменяли, работает то, что написано в .env.

Порядок поиска (берётся первое найденное):

| Что | Где ищется |
|---|---|
| Адрес сервера модели | `AI_PREMIERE_LLM_URL` → `LLM_URL`, `OLLAMA_URL`, `OPENAI_BASE_URL` (берутся как есть); без них — первый, который отвечает, из: `OLLAMA_IP` + `OLLAMA_PORT`, `OLLAMA_HOST` (без порта — `OLLAMA_PORT` или 11434, как у самой Ollama), `$url_ollama` из config.php системы, `127.0.0.1:11434` |
| Модель | `AI_PREMIERE_MODEL` → `GLOBAL_MODEL`, `LLM_MODEL`, `OLLAMA_MODEL`, `CHAT_MODEL`, `DEFAULT_MODEL` → `$global_model` из config.php → первая модель, которую отдаёт сам сервер |
| Размер контекста | `AI_PREMIERE_CONTEXT` → `GLOBAL_MODEL_CONTEXT`, `LLM_CONTEXT`, `OLLAMA_CTXSIZE` → `$ollama_ctxsize` → 32768 |
| Ключ (если шлюз его требует) | `AI_PREMIERE_API_KEY` → `LLM_API_KEY`, `OPENAI_API_KEY` |
| Протокол | `AI_PREMIERE_LLM_API` или `LLM_API` = `ollama` / `openai`; без них определяется сам |

- **Любой сервер:** работает и с Ollama, и с OpenAI-совместимыми серверами (vLLM, GLM, LM Studio и
  другие). Адрес с `/v1` на конце считается OpenAI-совместимым. Если у адреса нет `/api/chat`
  (как у Ollama), помощник сам пробует `/v1/chat/completions`.
- **Любая модель:** имя модели сверяется со списком моделей сервера. Если такой модели там нет,
  берётся подходящая из списка. Если шлюз принимает имена-псевдонимы, которых нет в его списке
  (например `chat`), поставьте `LLM_MODEL_CHECK=0`.
- Если сервер не умеет вызывать инструменты, помощник сам переходит на текстовый протокол вызовов.
- **Как проверить:** наведите мышь на строку «Модель: …» в шапке панели помощника. Там написано,
  какая модель используется и из какой строки .env она взята. То же показывает адрес
  `api/assistant.php` в браузере.

## Если что-то не работает

| Признак | Что проверить |
|---|---|
| Редактор не запускается | Под полосой загрузки написано, какой файл не пришёл и почему; нужен браузер с WebGPU или WebGL2 |
| После заливки по FTP — старая версия | Программа заливки пропустила файлы того же размера: включите «Перезаписывать всегда» |
| Нет звука при воспроизведении | Щёлкните по окну редактора: браузер включает звук только после нажатия |
| Видео не открывается | Формат или кодек, которого нет в списке выше; перекодируйте в MP4 (H.264 + AAC) |
| В панели «Нужно войти в систему» | Вход в вашу систему в этом же браузере и на этом же домене |
| «Не удалось создать папку для файлов» | Создайте `storage/ai-premiere` и дайте PHP право записи, или задайте `AI_PREMIERE_DATA_DIR` |
| Видео не загружается на сервер, ошибка 413 или «Сервер не передал PHP содержимое файла» | `client_max_body_size` для `api/files.php`, `post_max_size` и `upload_max_filesize` в PHP, `AI_PREMIERE_MAX_MB` — см. выше |
| Медиа проекта не нашлись при открытии | Файл в «Моих проектах» переименовали или удалили; верните имя или свяжите заново (Файл › Связать медиа) |
| Помощник: ошибка 413 / 504 | `client_max_body_size 20m` / `fastcgi_read_timeout 200s` для `api/assistant.php` — см. `nginx.conf.example` |

## Для разработчика

- Сборку делает GitHub Actions (`.github/workflows/studio.yml`) на каждое изменение ветки `main`:
  `studio/build/package.sh` собирает приложение (`apps/filmcraft-web`, wasm-bindgen), загрузчик частями
  (`apps/ai-premiere-boot`, trunk) и панель.
- Мост редактора: `apps/filmcraft-web/src/bridge.rs` — `window.aipremiere.request(метод, параметры)`,
  те же методы, что у канала управления (`crates/ui-egui/src/control.rs`), плюс `open`, `putMedia`,
  `mediaBlob`, `addFont`. В консоли браузера: `await aipremiere.execute('markers.add', {name: 'Здесь'})`.
- Сохранение на сервер: обработчик записи файлов (`deliver` в `apps/filmcraft-web/src/lib.rs`) отдаёт
  сохранённый проект `.fcproj` странице событием `aipremiere:save` → `api/files.php`; экспорт скачивается.
- Русский интерфейс — каталог FilmCraft `crates/ui-egui/src/i18n/ru.tsv` (язык и тема задаются при запуске
  в браузере).
- Основано на открытом проекте FilmCraft (github.com/storytold/filmcraft, MIT OR Apache-2.0) от команды
  ArtCraft; лицензии — в `NOTICE` и `LICENSE-*`.
